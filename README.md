# Developer Portfolio

Multi-page responsive developer portfolio.

## Pages
- `index.html` — Home
- `about.html` — About
- `projects.html` — Projects
- `experience.html` — Experience
- `contact.html` — Contact

## Run frontend
Open `index.html` in a browser. All navigation buttons work locally.

## Flask-ready backend
```bash
cd backend
pip install -r requirements.txt
python app.py
```

The future contact endpoint is available at `/api/contact`.
